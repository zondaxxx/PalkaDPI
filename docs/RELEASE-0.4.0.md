# PalkaDPI 0.4.0

Большой апдейт для обычного пользователя:

- автонастройка перебирает совместимые подписанные стратегии и сохраняет лучшую;
- выбор Discord, YouTube, Instagram, TikTok, X/Twitter, Telegram и своих доменов;
- DNS/TLS/HTTP-диагностика с несколькими замерами и медианой;
- smart recovery, откат и запасная стратегия после повторных сбоев;
- On Demand и отдельные профили для Wi-Fi/сотовой сети;
- Ed25519-подпись каталога, три офлайн-кэша, отзыв и совместимость версий;
- поиск, фильтры, избранное, история применений и статистика успешности;
- виджет состояния и команды Siri/Shortcuts;
- приватный диагностический JSON без IP и содержимого трафика.

IPA остаётся unsigned: подпишите `.widget`, затем `.tun`, затем приложение одним
Team/App Group. Тестировать Network Extension необходимо на физическом iPhone.
