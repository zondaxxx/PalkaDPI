# PalkaDPI 0.4.1

Исправление автоподбора после реального тестирования 0.4.0:

- старые однотипные v1-стратегии отозваны;
- каталог заменён десятью независимыми Apple-совместимыми upstream-цепочками;
- добавлены отдельные профили с обработкой QUIC/UDP 443 и голоса Discord;
- диагностика больше не считает любой HTTP-код до 500 успешным;
- каждый встроенный сервис проверяется по ожидаемому содержимому официального ответа;
- переход на постороннюю страницу-заглушку теперь считается ошибкой;
- исправлена проверка Telegram: старый `/robots.txt` постоянно возвращал 404.

IPA остаётся unsigned. Подписывайте `PalkaWidget.appex`, затем
`ByeByeDPITun.appex`, затем основное приложение с одним App Group.
