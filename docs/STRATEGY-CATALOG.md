# Онлайн-каталог стратегий

Каталог находится в корне репозитория: [`strategy-catalog.json`](../strategy-catalog.json).
Приложение скачивает его из ветки `main` по HTTPS, поэтому список можно обновлять
отдельно от IPA.

## Добавление стратегии

1. Создайте уникальный стабильный `id`.
2. Добавьте английские поля и, при возможности, русские варианты `nameRu`,
   `summaryRu`, `stabilityRu`.
3. Укажите сервисы, понятное назначение и HTTPS-ссылку на источник.
4. В `commandArgs` передавайте каждый аргумент отдельной JSON-строкой.
5. Используйте `{palka_targets}` вместо встроенного списка доменов Discord и YouTube.
6. Запустите проверку и откройте pull request:

```bash
swift scripts/validate_strategy_catalog.swift strategy-catalog.json
```

## Ограничения безопасности

- только схема версии `1`;
- не более 100 стратегий и 160 аргументов на стратегию;
- размер каталога не более 512 КиБ;
- `sourceURL` обязательно использует HTTPS;
- запрещены NUL, CR и LF внутри аргумента;
- после загрузки аргументы проходят Apple-валидатор `SBDConfig`;
- каталог не запускает shell-команды и не загружает исполняемые файлы.

Стратегии должны использовать только параметры, поддерживаемые встроенной версией
ByeDPI на Apple-платформах. Профили с `--fake`, raw packet injection, WinDivert или
файлами Windows zapret приниматься не будут.
