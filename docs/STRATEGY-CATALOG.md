# Подписанный каталог стратегий

Каталог находится в корне репозитория:
[`strategy-catalog.json`](../strategy-catalog.json). Его отделённая Ed25519-подпись:
[`strategy-catalog.json.sig`](../strategy-catalog.json.sig). Приложение принимает
обновление только после проверки подписи встроенным публичным ключом.

## Добавление стратегии

1. Создайте уникальный стабильный `id` и увеличьте `generation` каталога.
2. Добавьте английские поля и, по возможности, `nameRu`, `summaryRu`,
   `stabilityRu`.
3. Укажите поддерживаемые `services`, минимальные версии приложения/ядра и
   HTTPS-ссылку `sourceURL`.
4. В `commandArgs` передавайте каждый аргумент отдельной JSON-строкой.
5. Используйте `{palka_targets}`: приложение подставит домены выбранных сервисов
   и пользовательские домены.
6. Для снятия стратегии с распространения добавьте её `id` в `revokedStrategyIDs`.
   Для мягкого предупреждения используйте `deprecated: true`.
7. Проверьте, подпишите и повторно проверьте каталог:

```bash
swift scripts/validate_strategy_catalog.swift strategy-catalog.json strategy-catalog.json.sig

PALKA_CATALOG_PRIVATE_KEY=/secure/path/catalog-ed25519-private.pem \
  ./scripts/sign_strategy_catalog.sh strategy-catalog.json strategy-catalog.json.sig

swift scripts/validate_strategy_catalog.swift strategy-catalog.json strategy-catalog.json.sig
```

Приватный ключ никогда не добавляется в репозиторий. Владелец релиза хранит его
отдельно; публичный ключ зафиксирован в приложении и валидаторе.

## Что проверяется

- схема версии `2`, монотонное поколение и не более 100 стратегий;
- Ed25519-подпись точных байтов JSON до декодирования;
- защита от загрузки поколения старее уже проверенного кэша;
- совместимость `minimumAppVersion` и `minimumEngineVersion`;
- уникальность ID и отсутствие записи в `revokedStrategyIDs`;
- размер каталога до 512 КиБ, до 160 аргументов на стратегию;
- HTTPS для `sourceURL`, отсутствие NUL/CR/LF и ограничение длины аргументов;
- совместимость команды со встроенным Apple-валидатором `SBDConfig`.

Каталог не запускает shell-команды и не загружает исполняемые файлы. Профили с
WinDivert, `--fake`, raw packet injection или файлами Windows zapret отклоняются.

## Офлайн и откат

После успешной проверки приложение сохраняет до трёх поколений каталога в
App Group. При сетевой ошибке используется последний проверенный кэш. Пользователь
может выбрать предыдущее поколение на экране каталога; неподписанный или
несовместимый кэш никогда не применяется.
